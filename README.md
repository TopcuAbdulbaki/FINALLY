# FINALLY - Dosya Yönetim Uygulaması

Dosyaları taşıma, şifreleme, gizleme ve sıkıştırma işlemlerini gerçekleştiren Java GUI uygulaması.

## 🎯 Özellikler

- **Dosya Taşıma:** Kaynak dizinden hedef dizine dosyaları taşıyabilir
- **Dosya Şifreleme:** Caesar cipher algoritmasıyla metin dosyalarını şifreleyebilir/çözebilir
- **Dosya Gizleme:** Dosyaları Windows gizli dosya özniteliği ile gizleyebilir
- **Dosya Sıkıştırma:** Dosyaları ZIP formatında sıkıştırabilir
- **Dosya Filtreleme:** 
  - Tüm dosyalar (TXT, PDF, DOCX)
  - Sadece TXT dosyaları
  - Sadece PDF dosyaları
  - Sadece DOCX dosyaları

## 🛠️ Teknolojiler

- **Dil:** Java
- **GUI Framework:** Swing
- **Tarih:** 2023

## 📦 Kullanım

```bash
# Derlemek için
javac Main.java

# Çalıştırmak için
java Main
